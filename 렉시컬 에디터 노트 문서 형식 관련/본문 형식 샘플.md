# 본문 문서 형식 샘플

이 문서는 2차 주제의 본문 문서에 적용하는 화면 형식 샘플이다. 본문에는 전체 구현 목표와 TODO 계획만 작성하고, TODO의 상세 Step과 실제 구현 코드는 하위 문서에 작성한다.

## Lexical 블록 순서

아래 순서를 지킨다.

```text
h1  전체 구현 계획 제목
quote
  전체 목표

h2  TODO 계획
quote
  TODO 1~N 목록과 각 TODO의 결과물

h2  선행·후행 관계
quote
  TODO 간 의존성

h2  완료 기준
quote
  테스트·조회·화면 확인 조건
```

각 섹션 사이에는 빈 paragraph 2개를 둔다. 목록 항목 사이에는 빈 paragraph를 두지 않는다. 본문 계획 단계에서는 확인하지 않은 파일 경로, API 경로, 응답 예시, 코드를 확정된 사실처럼 넣지 않는다.

## 화면 예시

# LOT 조회 페이지네이션 서버 구현 전체 계획

> LOT 목록을 페이지네이션 방식으로 조회하고, 실제 HTTP 응답과 오류 조건까지 검증한다.

## TODO 계획

> - TODO 1. LOT 도메인 모델과 응답 계약 구현
> - TODO 2. LOT 페이지네이션 조회 API 구현
> - TODO 3. 샘플 데이터와 서버 응답 검증

## 완료 기준

> 페이지·크기 조건, 응답 메타데이터, 정렬 기준, 오류 응답, 실행 테스트 결과를 확인한다.

실제 저장 시 위 Markdown 모양을 그대로 content에 넣지 않는다. `heading`, `quote`, `paragraph`, `list`, `listitem` 등의 Lexical 노드로 변환해 JSON.stringify한 문자열을 저장한다.
