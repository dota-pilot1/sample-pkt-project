# Tauri 앱 릴리즈 런북

## 저장소와 산출물

- 저장소: <https://github.com/dota-pilot1/pkt-study-fullstack>
- 워크플로: `.github/workflows/tauri-release.yml`
- 운영 API Secret: `VITE_API_BASE`
- 자동 업데이트: GitHub Release의 `latest.json`
- 현재 기준 릴리즈: `v0.1.30`
- 빌드 방식: macOS 로컬 + Windows 수동 GitHub Actions

## 릴리즈 절차

`package.json`, `src-tauri/Cargo.toml`, `src-tauri/tauri.conf.json`의 버전을 같은 값으로 변경합니다.

1. `npm ci`, `npm run build`, `cargo check --manifest-path src-tauri/Cargo.toml`을 실행합니다.
2. 버전 파일과 `package-lock.json`을 커밋하고 `main`에 push합니다.
3. `vX.Y.Z` 태그를 push합니다. 태그 push만으로 빌드는 실행되지 않습니다.
4. macOS universal 앱과 DMG를 로컬에서 빌드·서명·공증합니다.
5. DMG를 GitHub Release에 직접 업로드합니다.
6. Windows 전용 워크플로를 `workflow_dispatch`로 한 번 실행합니다.

macOS GitHub 호스팅 러너 비용을 줄이기 위해 macOS는 개발 Mac에서 빌드합니다. Windows NSIS 설치 파일과 updater 서명 파일, `latest.json`은 저장소의 updater Secret을 사용하는 Windows Actions 작업이 게시합니다.

```bash
gh workflow run tauri-release.yml \
  --repo dota-pilot1/pkt-study-fullstack \
  --ref main \
  -f release_tag=vX.Y.Z
```

macOS updater 개인키의 비밀번호를 확인하지 못한 경우 updater artifact 생성을 끄고 공증된 DMG만 배포합니다. 이 경우 해당 버전의 macOS 사용자는 DMG를 한 번 수동 설치하며, 개인키를 임의의 다른 앱 키로 대체하지 않습니다.

## 확인

`gh run list --repo dota-pilot1/pkt-study-fullstack --limit 3`로 실행 상태를 확인합니다.
`gh release view vX.Y.Z --repo dota-pilot1/pkt-study-fullstack`로 산출물을 확인합니다.
`https://github.com/dota-pilot1/pkt-study-fullstack/releases/latest/download/latest.json`에 HEAD 요청을 보냅니다.

Release에 DMG, Windows 설치 파일, Windows `.sig`, `latest.json`이 있는지 확인합니다. 서명된 macOS 앱은 공증 티켓과 Gatekeeper 검증도 확인합니다. macOS updater artifact를 함께 만든 릴리스라면 `.app.tar.gz`와 `.sig`도 확인합니다.

기존 설치 앱은 사용자 SQLite를 유지하므로, 새 릴리스에서는 `PKT_STUDY_SEED_DB`를 이용해 번들 시드에만 있는 신규 메뉴·문서를 기존 DB에 병합하는지 확인합니다.
