# Tauri 앱 릴리즈 런북

## 저장소와 산출물

- 저장소: <https://github.com/dota-pilot1/pkt-study-tauri>
- 워크플로: `.github/workflows/tauri-release.yml`
- 운영 API Secret: `VITE_API_BASE`
- 자동 업데이트: GitHub Release의 `latest.json`
- 현재 기준 릴리즈: `v0.1.22`

## 릴리즈 절차

`package.json`, `src-tauri/Cargo.toml`, `src-tauri/tauri.conf.json`의 버전을 같은 값으로 변경합니다.

1. `npm ci`와 `npm run build`를 실행합니다.
2. 버전 파일과 `package-lock.json`을 커밋하고 `main`에 push합니다.
3. `vX.Y.Z` 태그를 push합니다.
4. GitHub Actions 성공 여부를 확인합니다.

태그 push 후 GitHub Actions가 macOS universal DMG, Windows 설치 파일, updater 서명 파일과 `latest.json`을 게시합니다.

## 확인

`gh run list --repo dota-pilot1/pkt-study-tauri --limit 3`로 실행 상태를 확인합니다.
`gh release view vX.Y.Z --repo dota-pilot1/pkt-study-tauri`로 산출물을 확인합니다.
`https://github.com/dota-pilot1/pkt-study-tauri/releases/latest/download/latest.json`에 HEAD 요청을 보냅니다.

Release에 DMG, Windows 설치 파일, `.sig`, `latest.json`이 모두 있는지 확인합니다. 서명된 macOS 앱은 Gatekeeper 경고 여부도 확인합니다.
