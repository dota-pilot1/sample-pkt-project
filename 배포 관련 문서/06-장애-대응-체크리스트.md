# 장애 대응 체크리스트

## 웹 장애

1. `curl -I https://hibot-docu.com`으로 CloudFront 응답을 확인합니다.
2. S3에 최신 `dist`가 올라갔는지 확인합니다.
3. CloudFront invalidation 완료 여부와 브라우저 캐시를 확인합니다.

## API/로그인 장애

1. `curl -sS https://api.hibot-docu.com/api/menus`를 실행합니다.
2. `sudo systemctl status sample-pkt-mes.service`를 확인합니다.
3. `sudo journalctl -u sample-pkt-mes.service -n 100 --no-pager`를 확인합니다.
4. `docker ps --filter name=sample-pkt-postgres`와 CORS/API base URL을 확인합니다.

## 앱 릴리즈 장애

1. `gh run view RUN_ID --repo dota-pilot1/pkt-study-tauri`로 실패 job을 확인합니다.
2. 세 버전 파일의 값이 일치하는지 확인합니다.
3. GitHub Secrets 이름과 등록 여부를 확인합니다.
4. macOS 오류면 Developer ID 인증서, p12 비밀번호, app-specific password를 확인합니다.
5. Release의 `latest.json`, `.sig`, DMG, Windows 설치 파일을 확인합니다.

## 롤백 원칙

- 웹: 이전 `dist` 재배포 후 CloudFront invalidation
- API: 백업 JAR 교체 후 systemd 재시작
- 앱: 이전 정상 GitHub Release 배포

DB volume 삭제, 운영 버킷 전체 삭제, 기존 서버 프로세스 강제 삭제는 확인 없이 수행하지 않습니다.
