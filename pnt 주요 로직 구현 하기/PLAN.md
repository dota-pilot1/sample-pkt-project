# P&T LOT 품질 판정 주요 로직 구현 계획

## 목표

> 생산 작업지시를 LOT으로 나누어 관리하고, 완료된 LOT의 수량·수율·불량률·상태를 기준으로 다음 단계 진행 또는 출하 가능 여부를 판정한다. 실제 Tester·설비 제어는 이 프로토타입 범위에서 제외한다.

```text
제품 기준정보 → 작업지시 → LOT 생성·관리 → LOT 결과 데이터 확인
→ LOT 품질 판정 기준 적용 → 출하 가능 / 재검 / 보류 판정
```

## 구현 범위

1. 제품 관리: 제품 코드, 이름, 패키지 타입, 제품 구분, 활성 상태 관리
2. 작업지시·LOT 관리: 작업지시를 기준으로 LOT을 생성하고 계획 수량·공정·상태를 추적
3. LOT 품질 판정 기준: 제품별 버전 기준과 수율·불량률·정상 수량·LOT 상태 조건 저장
4. LOT 품질 판정 실행: 완료 LOT에 기준을 적용해 조건별 결과와 최종 처분을 저장
5. 판정 이력: 어떤 LOT에 어떤 버전의 기준을 적용했는지, 실패 사유가 무엇인지 조회

## 제외 범위

- ATE, Handler, PLC, SECS/GEM, OPC UA 등 실제 설비 제어·통신
- Unit별 전류·전압·기능 측정값과 Fail Bin 수집
- 실시간 센서 스트리밍, 설비 알람, 레시피 배포
- 출하 ERP 연계와 전자결재

## 설계 결정

- LOT은 생산 단위이며, 품질 판정은 이미 수집된 LOT 집계 데이터를 대상으로 한다.
- 수율과 불량률은 `정상 수량 / 검사 수량`, `불량 수량 / 검사 수량`에서 계산한다.
- 품질 기준은 `제품 + 기준명 + 버전` 단위로 관리하고, 승인된 버전은 수정하지 않는다.
- 기준의 조건은 여러 개를 둘 수 있으며, 모두 통과해야 `출하 가능`이다.
- 기준 적용 결과는 LOT 현재값만 덮어쓰지 않고 판정 이력으로 저장한다.
- 실제 장비 테스트가 필요해지면 별도 `Test Run` 컨텍스트를 추가하고 그 결과를 LOT 집계값의 원천으로 연결한다.


## 전체 완료 기준

- 활성 제품을 선택해 버전 있는 LOT 품질 판정 기준을 등록할 수 있다.
- 기준에는 최소 수율, 최대 불량률, 최소 정상 수량, 대상 LOT 상태를 함께 저장할 수 있다.
- 완료 LOT에 기준을 적용하면 각 조건의 통과·실패와 최종 `출하 가능 / 재검 / 보류`가 남는다.
- 과거 판정은 당시 기준 버전과 LOT 집계값을 재현할 수 있다.
- 백엔드 테스트와 프론트 lint/build가 통과한다.
