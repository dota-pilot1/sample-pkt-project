# 스텝2 - LOT 관리 페이지 구현

## 목표

> 작업지시를 실제 생산·추적 단위인 LOT으로 분할하고, LOT의 생산 결과 데이터를 품질 판정이 사용할 수 있게 관리한다.

## 업무 흐름

```text
제품 선택 → 작업지시 생성 → 작업지시 수량을 하나 이상의 LOT으로 분할
→ LOT 생산 진행·완료 → 정상/불량 수량과 수율 확인 → LOT 품질 판정 기준 적용
```

## 현재 화면 책임

- 작업지시 목록에서 여러 작업지시의 제품·계획 수량·상태를 조회한다.
- LOT 등록 시 작업지시를 선택하고, 작업지시 제품과 LOT 제품의 일치 여부를 검증한다.
- LOT 목록은 `LOT 번호 / 제품 / 제품 구분 / 현재 공정 / 계획 수량 / 상태 / 정상·불량 / 수율`을 보여준다.
- Tester는 LOT의 고정 속성이 아니므로 LOT 목록·등록 폼에서 관리하지 않는다. 향후 장비 연동이 필요하면 공정 실행 또는 Test Run 이력에 둔다.

## LOT 데이터와 품질 판정의 경계

| LOT 데이터 | 품질 판정에서의 사용 |
| --- | --- |
| 계획/검사 수량 | 정상 수량·불량률의 분모 또는 추적 정보 |
| 정상 수량 | 최소 정상 수량 조건 |
| 불량 수량 | 불량률 계산 |
| 수율 | 최소 수율 조건 |
| LOT 상태 | 완료 상태 조건 |

1차 프로토타입은 기존 시드의 정상·불량·수율 값을 사용한다. 실제 설비 또는 Tester가 데이터를 보내는 구현은 범위 밖이다.

## 완료 기준

- 작업지시를 선택해 여러 LOT을 등록할 수 있다.
- 완료 LOT에서 정상/불량과 수율을 조회할 수 있다.
- LOT의 상태·수량 데이터가 다음 단계 LOT 품질 판정의 입력으로 충분하다.

## 후행 작업

- `스텝3 - LOT 품질 판정 기준 구현 계획`: 완료 LOT의 제품·상태·집계값에 적용할 기준을 등록한다.
