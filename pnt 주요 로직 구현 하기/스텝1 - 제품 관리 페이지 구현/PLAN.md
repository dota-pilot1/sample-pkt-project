# 스텝1 - 제품 관리 페이지 구현

## 목표

> 작업지시, LOT, LOT 품질 판정 기준이 공통으로 참조하는 제품 기준정보를 관리한다.

## 구현 결과

- 제품 코드, 제품명, 패키지 타입, 활성 상태를 관리한다.
- 제품을 `원자재`, `반제품`, `완제품`으로 분류한다.
- LOT 목록과 LOT 품질 판정 기준에서는 제품을 FK로 참조한다.
- 비활성 제품은 신규 작업지시·LOT·품질 기준 등록 대상에서 제외한다.

## 데이터 모델

| 필드 | 용도 |
| --- | --- |
| 제품 코드·제품명 | 생산·LOT·품질 기준의 공통 식별 정보 |
| 패키지 타입 | P&T 제품 특성 표시 |
| 제품 구분 | 원자재 / 반제품 / 완제품 구분 |
| 활성 상태 | 신규 업무에서 선택 가능한지 여부 |

## 완료 기준

- PKT 샘플 제품을 제품 관리 화면에서 조회하고 등록·수정·비활성화할 수 있다.
- LOT 목록에서 제품 코드와 제품 구분을 확인할 수 있다.
- 다음 스텝의 품질 기준 등록 화면에서 활성 제품만 선택할 수 있다.

## 후행 작업

- `스텝2 - 롯 관리 페이지 구현`: 선택 제품을 기준으로 작업지시와 LOT을 연결한다.
- `스텝3 - LOT 품질 판정 기준 구현 계획`: 제품별 기준과 버전을 등록한다.
