# 스텝4 - LOT 등록 시 입력 조건 제한

## 목표

> 작업지시의 계획 수량 범위 안에서만 LOT을 분할 등록한다. 프론트는 즉시 안내하고, 서버는 동시 요청을 포함해 수량 초과를 최종 차단한다.

## 사용자 시나리오

```text
작업지시 WO-PT-001의 계획 수량은 10,000 EA다.
→ 이미 등록된 LOT의 수량 합계는 8,000 EA다.
→ 사용자는 잔여 2,000 EA 이하로 새 LOT을 등록할 수 있다.
→ 2,001 EA를 입력하면 프론트가 즉시 초과를 안내한다.
→ 서버도 저장 직전에 합계를 다시 계산해 초과 저장을 거절한다.
```

## 적용 규칙

1. 작업지시 상태가 `승인` 또는 `진행`일 때만 LOT을 생성한다.
2. LOT 수량은 0보다 커야 한다.
3. 완료·취소된 작업지시에는 LOT을 추가할 수 없다.
4. LOT의 제품은 선택한 작업지시의 제품으로 자동 결정하며, 다른 제품으로 변경할 수 없다.
5. 잔여 수량이 0이면 LOT 등록 버튼과 등록 동작을 비활성화한다.
6. 서버는 `기존 LOT 수량 합계 + 요청 LOT 수량 ≤ 작업지시 계획 수량`을 저장 시점에 검증한다.

## 화면 구성

작업지시 상세에 아래 요약 영역을 표시한다.

| 항목 | 설명 |
| --- | --- |
| 계획 수량 | 작업지시가 지시한 전체 생산 수량 |
| LOT 배정 합계 | 해당 작업지시에 이미 등록된 LOT 수량의 합계 |
| 잔여 수량 | 계획 수량 - LOT 배정 합계 |
| 생성 LOT 목록 | LOT 번호, 수량, 상태, 생성 시각 |

LOT 등록 화면은 작업지시를 먼저 선택하고, 제품은 읽기 전용으로 표시한다. 수량 입력 아래에는 `등록 가능 잔여 수량: N EA`를 표시한다.

## 단계

### Step 1. 작업지시 상태와 LOT 집계 확인

목적: 현재 작업지시 상태값과 LOT-작업지시 연결 구조를 확인하고, LOT 합계를 조회할 위치를 정한다.

- 작업지시의 실제 상태 enum과 승인·진행·완료·취소 상태 전이 여부를 확인한다.
- LOT이 작업지시를 참조하는 필드와 수량 필드를 확인한다.
- 작업지시별 LOT 수량 합계와 잔여 수량을 계산하는 조회 메서드를 설계한다.

### Step 2. 서버 LOT 생성 검증 구현

목적: 화면을 우회한 요청과 동시 요청에도 계획 수량 초과 LOT이 저장되지 않게 한다.

- LOT 생성 전에 작업지시 존재 여부와 생성 가능 상태를 확인한다.
- LOT 수량이 양수인지 검증한다.
- 작업지시 제품을 LOT에 자동 적용하거나, 요청 제품이 있으면 작업지시 제품과 일치하는지 검증한다.
- 트랜잭션 안에서 기존 LOT 합계를 다시 계산하고 잔여 수량 초과 요청을 거절한다.
- 작업지시 상세 응답에 계획 수량, LOT 배정 합계, 잔여 수량, LOT 목록을 제공한다.

### Step 3. 작업지시 상세와 LOT 등록 폼 연결

목적: 사용자가 남은 수량을 보며 안전하게 LOT을 분할 등록하도록 한다.

- 작업지시 목록에서 상세 화면 또는 드로어를 연다.
- 상세에 계획 수량·LOT 배정 합계·잔여 수량·생성 LOT 목록을 표시한다.
- 등록 폼에서 제품 선택을 제거하고 작업지시 제품을 읽기 전용으로 표시한다.
- 수량 입력값이 잔여 수량보다 크면 즉시 오류 문구를 보여주고 저장 버튼을 비활성화한다.
- 작업지시 상태가 생성 불가이거나 잔여 수량이 0이면 LOT 등록 버튼을 비활성화한다.

### Step 4. 예외 흐름과 동기화 검증

목적: 프론트 안내와 서버 무결성이 같은 규칙을 따르는지 확인한다.

- 승인·진행 상태의 작업지시에서는 잔여 수량 범위로 LOT을 생성할 수 있는지 확인한다.
- 완료·취소 상태의 작업지시에서 버튼과 API가 모두 차단되는지 확인한다.
- 0, 음수, 잔여 수량 초과 값을 각각 확인한다.
- 여러 화면 또는 요청이 동시에 같은 잔여 수량을 사용해도 서버가 한 요청만 허용하는지 확인한다.
- LOT 등록 후 작업지시 상세의 배정 합계·잔여 수량·LOT 목록이 즉시 갱신되는지 확인한다.

## 완료 기준

- 작업지시의 계획 수량을 초과하는 LOT은 어떤 경로로도 저장되지 않는다.
- LOT 제품은 작업지시 제품과 항상 일치한다.
- 사용자는 작업지시 상세에서 LOT 분할 현황과 남은 수량을 확인할 수 있다.
- 프론트 lint/build와 백엔드 컴파일·관련 테스트가 통과한다.

## 후행 작업

- LOT이 완료되면 제품별 LOT 품질 기준을 적용해 통과·실패와 출하 가능 여부를 판정한다.
