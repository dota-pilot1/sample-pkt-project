# 스텝3 - LOT 품질 판정 기준 구현 계획

## 목표

> 제품별 LOT 출하·다음 공정 진행 기준을 버전 단위로 저장하고, 기준과 하위 조건을 테이블 형태로 조회·관리한다. 이 단계에서는 LOT에 기준을 적용하거나 장비를 제어하지 않는다.

## 사용자 시나리오

```text
관리자가 PKT-C를 선택한다.
→ `PKT-C 출하 기준 v1`을 등록한다.
→ 완료 상태, 수율 98% 이상, 불량률 2% 이하, 정상 수량 2,000 EA 이상 조건을 추가한다.
→ 기준을 승인한다.
→ 다음 단계에서 완료 LOT에 이 기준을 적용한다.
```

## 구현 범위

- 제품별 품질 기준 헤더 등록·목록·상세 조회
- 기준명, 버전, 설명, 대상 LOT 상태, 통과/실패 처분 등록
- 수율·불량률·정상 수량·LOT 상태 조건의 추가·수정·삭제
- Draft / Approved / Inactive 상태 전이
- 승인 기준 읽기 전용과 새 버전 생성 정책
- 기준 목록과 선택 기준의 조건 테이블 UI

## 제외 범위

- LOT에 기준을 적용해 실제 통과·실패를 계산하는 기능
- LOT 상태를 자동으로 출하·보류·재검으로 변경하는 기능
- Tester, 센서, PLC, 전류·전압·Fail Bin 데이터

## 화면 구성

```text
왼쪽: 품질 기준 목록
  제품 / 기준명 / 버전 / 상태 / 조건 수

오른쪽: 선택 기준 상세
  제품, 버전, 대상 LOT 상태, 통과·실패 처분
  └─ 조건 테이블
       순서 | 판정 항목 | 비교 | 기준값 | 설명
```

| 순서 | 판정 항목 | 비교 | 기준값 | 설명 |
| --- | --- | --- | --- | --- |
| 1 | LOT 상태 | 같음 | 완료 | 완료 LOT만 판정 가능 |
| 2 | 수율 | 이상 | 98.0% | 최소 수율 |
| 3 | 불량률 | 이하 | 2.0% | 최대 불량률 |
| 4 | 정상 수량 | 이상 | 2,000 EA | 최소 출하 수량 |

## 단계

### Step 1. 모델과 검증 규칙 확정

목적: `lot_quality_standards`, `lot_quality_rules`의 엔티티·마이그레이션 범위와 지표별 검증을 확정한다.

- 제품이 활성 상태인지 확인한다.
- 기준명·제품·버전의 중복을 막는다.
- 수율·불량률은 0~100, 정상 수량은 0 이상으로 제한한다.
- 기준에는 최소 한 개 이상의 조건이 필요하며, 초기 등록 기본값은 LOT 상태 `완료` 조건으로 둔다.

### Step 2. 기준 관리 API 구현

목적: 목록·상세·등록·수정·승인·비활성화 API를 만들고, 기준과 조건을 트랜잭션으로 저장한다.

- Draft 기준만 편집·삭제할 수 있다.
- 승인 시 조건을 검증하고 `approvedAt`을 기록한다.
- Approved 기준은 수정하지 않고 새 버전을 생성한다.
- 응답에는 제품 요약, 기준 메타데이터, 정렬된 조건 목록을 포함한다.

### Step 3. 품질 기준 관리 페이지 구현

목적: 기준 목록과 선택 기준의 조건 테이블을 한 화면에서 관리한다.

- 메뉴 위치는 `테스트`가 아니라 `생산 실행` 또는 향후 `품질` 그룹으로 확정한다. 현재 프로토타입에서는 `생산 실행 > LOT 품질 기준`을 우선 사용한다.
- 왼쪽 목록은 요약만 보여주고, 조건은 오른쪽 상세 테이블에서 보여준다.
- 기준 등록·편집 화면은 조건 행 추가 방식으로 만든다.
- Approved 상태에서는 편집 영역 대신 읽기 전용 안내와 `새 버전 생성` 액션을 보여준다.

### Step 4. 시드와 검증

목적: 화면 데모에 필요한 제품별 기준을 만들고 API·프론트 연결을 확인한다.

- PKT-A~D에 Draft 또는 Approved 기준을 시드한다.
- `PKT-C 출하 기준 v1`에는 완료·수율 98%·불량률 2%·정상 2,000 EA 조건을 넣는다.
- 백엔드 컴파일/테스트와 프론트 lint/build를 실행한다.
- 빈 목록, 조건 누락, 유효하지 않은 기준값, 승인 후 편집 시도를 확인한다.

## 완료 기준

- 관리자가 활성 제품을 선택해 품질 기준과 조건을 저장할 수 있다.
- 기준 목록과 선택 상세 테이블에서 조건이 정확한 순서로 보인다.
- 승인된 기준은 수정할 수 없고 새 버전으로만 변경할 수 있다.
- 기준은 아직 LOT을 바꾸지 않으며, 다음 스텝의 판정 실행이 안전하게 참조할 수 있다.
