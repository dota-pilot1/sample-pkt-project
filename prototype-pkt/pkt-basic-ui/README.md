# pkt-basic-ui

PKT 제품 화면을 위한 50가지 기본 UI 실습 프론트엔드.

## Dev

```bash
npm install
npm run dev   # http://localhost:4200
```

## Env

- `NEXT_PUBLIC_API_URL` — 백엔드 API URL (기본 `http://localhost:4201`)

## Ports

| 서비스 | 포트 |
| --- | --- |
| Front (Next.js) | 4200 |
| Backend (Spring Boot) | 4201 |
| Postgres (host) | 5454 |
