# PKT MES 구현 로드맵

## 목표

SK하이닉스 PKT(Package Test) 업무를 가정해 제품·Package, 공정 Route, LOT, Tester, 테스트 프로그램, 검사 결과, 수율과 이력 추적을 연결한다.

## 첫 번째 수직 기능

```text
제품 등록
→ LOT 생성
→ 테스트 프로그램 선택
→ Tester 배정
→ 테스트 시작/종료
→ Pass/Fail 입력
→ 수율 계산
→ LOT 이력 조회
```

## 도메인 구현 순서

1. 제품/Package 기준정보
2. 공정 Route와 Route Step
3. Tester 및 테스트 프로그램
4. LOT와 LOT 상태
5. LOT 테스트 작업지시
6. 테스트 결과·Fail Bin·불량 코드
7. 수율·처리량·장비 분석
8. LOT genealogy와 재작업 이력

## 기존 공통 기반 재사용

- JWT 인증과 RBAC
- DB 기반 메뉴
- Spring Boot DDD 4-Layer
- Next.js/React FSD
- TanStack Query와 공통 Axios
