# Tauri 앱과 AX 시대

> Tauri 앱은 가볍고 빠른 데스크톱 실행 환경에 업무 데이터와 지식 흐름을 결합할 수 있어, 폐쇄망 기반의 AX(Artificial Intelligence Transformation) 업무 도구에 잘 맞는다.

## 왜 Tauri인가

Tauri는 웹 기술로 화면을 만들면서도 데스크톱 앱으로 배포할 수 있다. Electron보다 작은 실행 파일과 낮은 메모리 사용량을 기대할 수 있고, 사용자는 브라우저를 열거나 별도의 개발 환경을 준비하지 않아도 업무를 시작할 수 있다.

특히 제조·검사·설비 현장에서는 네트워크 품질과 보안 정책이 일정하지 않다. Tauri 앱은 로컬 파일·SQLite·캐시를 활용해 네트워크가 제한된 환경에서도 화면과 기본 업무 흐름을 안정적으로 제공할 수 있다.

## 폐쇄망 노트와의 궁합

폐쇄망 노트는 단순한 메모장이 아니라, 현장의 경험과 판단을 축적하는 지식 시스템이다. Tauri 앱에 노트 기능을 담으면 다음 흐름을 한 공간에서 연결할 수 있다.

- 작업 중 발견한 현상과 조치 내용을 즉시 기록
- LOT·공정·장비·검사 결과와 관련 노트 연결
- 외부 전송 없이 로컬에 초안과 이력 보존
- 승인된 시점에만 내부 서버와 동기화
- 조직에서 관리하는 버전의 앱과 문서 형식 배포

이 구조는 폐쇄망의 보안 요구를 지키면서도, 현장 지식을 반복 가능한 데이터로 바꾸는 기반이 된다.

## 핵심 기능 요약

1. **계층형 노트 관리** — 1차 메뉴·2차 메뉴·문서 구조로 업무 지식과 학습 내용을 체계적으로 분류한다.
2. **문서 제목·본문 통합 검색** — 필요한 문서를 제목이나 본문 내용으로 빠르게 찾는다.
3. **리치 텍스트 문서 편집** — 일반 문장, 목록, 인용, 표 등 다양한 형식으로 현장 지식을 기록한다.
4. **개발 노트와 코드 블록** — Spring, Java, DB, React·TypeScript 등 기술별 노트를 코드 하이라이팅과 함께 관리한다.
5. **TODO·하위 문서 관리** — 큰 구현 과제를 단계별 문서로 나누고, API·Front 작업 흐름과 진행 상태를 연결한다.
6. **메뉴·문서 순서 편집** — 드래그 앤 드롭으로 업무 순서와 문서 노출 순서를 현장에 맞게 조정한다.
7. **MES 업무 지식 연결** — LOT, 공정, 설비, 검사 결과와 관련 노트를 연결해 이력과 판단 근거를 함께 확인한다.
8. **로컬 저장·내부 API 연동** — 폐쇄망에서는 로컬에 안전하게 보존하고, 허용된 환경에서만 내부 서버와 동기화한다.

## AX 관점에서의 의미

AX는 AI를 별도 채팅 도구로 추가하는 것보다, 사람이 실제로 일하는 흐름 안에 지식과 자동화를 배치하는 데 의미가 있다. Tauri 앱은 업무 화면, 노트, 로컬 데이터, 내부 API를 하나의 사용 경험으로 묶기 쉽다.

예를 들어 사용자는 LOT 이력을 확인하면서 관련 작업 노트를 읽고, 과거 유사 사례를 검색하고, 조치 결과를 다시 기록할 수 있다. 이후 내부 AI 기능을 연결하면 축적된 노트를 바탕으로 요약·검색·체크리스트 생성·이상 징후 설명을 지원할 수 있다.

## 기대 효과

| 관점 | 기대 효과 |
| --- | --- |
| 보안 | 민감한 업무 데이터의 외부 전송을 최소화 |
| 현장성 | 네트워크와 무관하게 기록·조회 가능한 업무 도구 제공 |
| 지식화 | 개인의 경험을 검색 가능한 조직 자산으로 축적 |
| 운영 | 서명된 설치 파일과 버전 관리로 배포 범위 통제 |
| 확장성 | 웹 UI, 로컬 저장소, 내부 API, AI 기능을 단계적으로 결합 |

## 정리

Tauri는 단순히 웹 화면을 데스크톱으로 포장하는 기술이 아니다. 폐쇄망에서 안전하게 실행되고, 현장의 업무 맥락과 지식을 보존하며, 필요한 시점에 내부 시스템과 AI를 연결하는 경량 업무 플랫폼이 될 수 있다. 따라서 PKT와 같은 MES 학습·운영 환경에서는 Tauri 앱을 폐쇄망 노트와 AX 실험을 함께 추진하는 현실적인 기반으로 활용할 수 있다.
